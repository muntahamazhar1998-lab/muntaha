Reflection
While completing the Unit 1 OOP project, I applied object‑oriented programming principles to structure the Python code in a modular and organized way. I used classes as blueprints that defined both the attributes and behaviors of the objects created from them. Encapsulation was implemented by keeping the internal data of each object protected and exposing functionality through methods, which helped maintain predictable interactions within the program. Inheritance allowed the child class to reuse and extend the functionality of the parent class, reducing duplication and making the design more flexible.

As I worked through the TODO prompts, I examined how each method contributed to the overall behavior of the class. Running the starter file helped me understand the existing structure, and completing the implementation allowed me to see how new features could be added without disrupting the original design. After finishing the code, I updated this README.md in past tense to document my approach and verified that my work aligned with the submission checklist.

The concepts of encapsulation and inheritance reminded me of real‑world systems I have worked with in front desk operations and telecom sales. Each department functioned like a class with its own responsibilities, while employees acted as objects with individual attributes such as skills and permissions. During the FIFA World Cup Qatar 2022, certain staff members inherited additional responsibilities such as VIP handling or multilingual support, similar to how a child class extends a parent class. Proper error handling also played a major role in preventing small issues from becoming major operational failures, which mirrors how exceptions must be managed in programming to keep systems stable.

Completing this project helped me understand how OOP principles can be applied to emerging technologies I am interested in, such as customer service automation, smart kiosks, and AI‑driven support systems. A modular class structure could model users, service requests, authentication layers, and device interactions. Inheritance would allow specialized versions of these components to evolve without rewriting the entire system. This assignment strengthened my ability to design scalable, maintainable code and showed me how these foundational principles can support my long‑term career goals in technology and automation.
